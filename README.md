# bluff-and-bridge

One-page landing for a 1:1 faith walk offer in Stillwater, MN. Working name: **Bluff & Bridge** (set in `SITE_NAME` in `js/site.js` and `.site-name` in the HTML).

Open `index.html` in a browser, or from this directory run:

```bash
python3 -m http.server
```

Deployed as static assets via Cloudflare Workers (`wrangler.jsonc`).
